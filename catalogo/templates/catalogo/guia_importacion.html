Cómo preparar tu archivo

Coloca los encabezados en la primera fila y una cuenta por fila a partir de la segunda. Usa los nombres de columna indicados abajo, sin acentos. El orden de las columnas puede variar.

Columnas del archivo
Columna Obligatoria Formato y ejemplo
cuenta Sí Texto, máximo 20 caracteres. Es la clave de tu cuenta; conserva ceros iniciales y separadores. Ejemplos: 001, 001.01, 1100-02. No debe estar vacía.
descripcion Sí Texto con el nombre de la cuenta, por ejemplo Bancos nacionales. Puede contener acentos y espacios. No debe estar vacío. Un nombre preciso ayuda a sugerir la relación SAT.
nivel No; recomendado Número entero de 1 a 20, sin decimales. Indica la profundidad de esa cuenta: 1 para la cuenta principal, 2 para su subcuenta, 3 para el siguiente nivel. Úsalo para filtrar correctamente catálogos con claves sin separadores.
codigoagrupador No Texto con un código existente en el catálogo SAT, por ejemplo 102.01. No uses el número de tu cuenta propia en esta columna. Puedes dejarla vacía u omitirla para obtener una relación sugerida; si proporcionas un código inexistente, esa fila se reporta como error.
Columnas alternativas: nivel1, nivel2, nivel3 y nivel4

Son opcionales y representan los componentes de la jerarquía. Cada celda debe contener un entero sin decimales, mayor o igual a cero, o quedar vacía. Por ejemplo: nivel1=1, nivel2=0, nivel3=5, nivel4 vacío corresponde a profundidad 3. Un cero cuenta como un componente presente. No necesitas estas columnas si ya usas nivel.

Formato del archivo

Excel (.xlsx): guarda el catálogo en la hoja activa, con encabezados en la fila 1, sin títulos encima ni celdas combinadas. Configura cuenta y codigoagrupador como Texto antes de capturarlos o pegarlos. Escribir 001 como número puede convertirlo en 1; aplicar formato de texto después no recupera los ceros perdidos. Guarda nivel como número entero. El formato antiguo .xls no se admite.

CSV (.csv): usa codificación UTF-8 y coma como separador de columnas. Si tu hoja de cálculo exporta con punto y coma, cambia el separador a coma. Si una descripción contiene comas, enciérrala entre comillas dobles: "Bancos, cuenta principal".

Ejemplo listo para guardar como CSV

cuenta,descripcion,nivel,codigoagrupador
1000,Caja,1,
1000.01,Caja y efectivo,2,
1100,Bancos,1,
1100.01,Bancos nacionales,2,102.01

La coma al final de las primeras filas deja vacío el código SAT para solicitar una sugerencia. En Excel usa las mismas cuatro columnas, con cada dato en su propia celda.

Cómo se aplica el nivel elegido

Si eliges hasta el nivel 2, se importan las cuentas de niveles 1 y 2; las de nivel 3 o superior se omiten. Con Todos los niveles se incluyen todas las profundidades del archivo.

Para cada fila se usa primero nivel. Si está vacío, se toma el último componente presente entre nivel1 y nivel4. Si tampoco hay componentes, se cuentan los segmentos de cuenta separados por punto, guion o barra: 1000.01.001 tiene nivel 3. Una clave sin separadores se interpreta como nivel 1 cuando no se indica otro nivel.

Si una cuenta ya existe en esta organización, se actualiza con los datos del archivo; usa una sola fila por cuenta. Las cuentas omitidas por nivel no se eliminan. Las filas válidas se importan aunque otras tengan errores; el resultado indica qué filas debes corregir. Revisa y confirma las relaciones sugeridas en el catálogo antes de generar un manual.
